## 🎯 Hedefim

Mobil uygulama geliştirme alanında özellikle Flutter ve Dart kullanarak kendimi geliştirmeyi hedefliyorum. Bu süreçte responsive arayüzler oluşturma, REST API entegrasyonu, state management, form ve kullanıcı giriş işlemleri, yerel veri saklama ve temel backend bağlantıları gibi konularda deneyim kazanmak istiyorum. Bunun yanında temiz kod yazımı, katmanlı proje yapısı ve Git kullanımı gibi yazılım geliştirme süreçlerinde de kendimi ilerleterek gerçek projelerde kullanılabilecek, sürdürülebilir mobil uygulamalar geliştirmeyi amaçlıyorum.
